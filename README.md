> מומלץ בחום רב לתכנת את התוכניות המופיעות כאן. הן אינן קלות, אבל זהו הידע עימו אנו מצפים שתגיעו לקורס.

## המשימה

עליך לכתוב ספרייה (מודול בלשון נכר) של **רשימה** ותור **דינמיים**.

**מימוש הרשימה והתור יהיה ללא לולאות, מלבד בפונקציית ההשמדה של הרשימה.**
לא. אתם לא יכולים להשתמש ב-`goto`. חוכמולוגים. גם ברקורסיה לא.

## דרישות נוספות (לצורך הבדיקה האוטומטית)

- **אסור לשנות** את `include/list.h` ואת `include/queue.h`. ההגדרות המדויקות של כל פונקציה (ערכי החזרה, מקרי קצה) כתובות בהערות שבקבצים – קראו אותן.
- את המימוש כותבים ב-`src/list.c` וב-`src/queue.c` בלבד. שם גם מגדירים את ה-`struct`-ים.
- ערכי האיברים הם `int`. שימו לב: הסכום של כמה `int`-ים גדולים לא נכנס ב-`int`.
- כל זיכרון שהוקצה חייב להשתחרר. הבדיקות רצות עם AddressSanitizer, שמזהה דליפות זיכרון, `free` כפול וגישה לזיכרון משוחרר.
- הקוד חייב להתקמפל בלי אזהרות (`-Wall -Wextra -pedantic`).
- כדאי לממש את התור בעזרת הרשימה.

> רמז: אם אסור לולאה, איך יודעים מה האורך ומה הממוצע? מה הרשימה צריכה **לזכור** כל הזמן?

## איך עובדים

```bash
make            # קימפול
make test       # הרצת כל הבדיקות
make asan       # הבדיקות עם AddressSanitizer (דליפות זיכרון)
make rules      # בדיקת החוק: אין לולאות / goto / רקורסיה
./tests/grade.sh     # הציון שתקבלו, בדיוק כמו בבדיקה האוטומטית
./tests/grade.sh -v  # אותו דבר, עם פירוט של מה נכשל
./build/tests list_remove   # הרצת בדיקה אחת
```

צריך Linux (או WSL / Mac) עם `gcc`, `make` ו-`python3`.
